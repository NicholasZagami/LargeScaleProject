# Large Scale Data Management – Steam Reviews Data Warehouse

This repository contains the implementation and documentation of a **Large Scale Data Management** project focused on the analysis of the **Steam Games and Reviews dataset**.

The project covers the complete data pipeline, including:
- data ingestion and cleaning from heterogeneous sources,
- dimensional modeling using a **Dimensional Fact Model (DFM)**,
- logical design of a **star schema Data Warehouse**,
- ETL processes for data integration,
- interactive analytical dashboards for data exploration.

The goal of the project is to support large-scale analytical queries on user reviews and game metadata, enabling insights on trends, engagement, and market characteristics within the Steam ecosystem.
